Up and running

  1. Download and run the Windows installer.
  2. Approve the Windows administrator prompt.
  3. Open Sundial to configure accounts and limits.

The installer upgrades an existing installation while keeping its settings. The current build is unsigned, so Windows may show a publisher warning.
